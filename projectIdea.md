# This is a project where we can manage the other projects.
- for now it will be a simple project with a very professional look.
- this will be a react project (so simply use a command to create the project).
- it should be in react, js, react router etc.
- make this project scaleable.


## UI
- the UI will be simple and atrractive.
- it should be like dashboard style.

## Features
- can create a project, and sub projects
- for every project there are multiple tools in side nav bar.
- 


## Tools (apps)
1. Tasks/issues manager.
- contain multiple types of tasks [Current, Later, Done/completed etc.]
- Tags for tasks [feature, bug, documentation, refactor, testing,  etc.]
- These tasks are saved in local-storage of browser.
